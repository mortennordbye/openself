# Diagram icons

Kept here so rendering needs no network and gives the same output every time.

- `mdi-*.svg`: [Material Design Icons](https://pictogrammers.com/library/mdi/) 7.4.47
  (Apache 2.0), from the `@mdi/svg` package, coloured for the diagrams (`-amber` for the accent).
- `git.svg`, `github-light.svg`, `python.svg`: from
  [dashboard-icons](https://github.com/homarr-labs/dashboard-icons); the logos belong to their owners.
