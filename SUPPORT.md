# Support

- **How do I...?** Start with the [documentation](https://mortennordbye.github.io/openself/),
  in particular [Troubleshooting](https://mortennordbye.github.io/openself/troubleshooting/).
- **Something is broken, or an idea:** open an [issue](https://github.com/mortennordbye/openself/issues/new/choose).
- **A security problem:** see [SECURITY.md](SECURITY.md); do not open a public issue.

Never paste profile text, keys or a password manager session into an issue.
